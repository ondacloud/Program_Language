# operator

## 개념과 사용 시점

산술·비교·논리 연산자로 값을 계산합니다. /는 실수 나눗셈, ~/는 정수 나눗셈입니다.

## 실행

[과정 준비 안내](../README.md)를 먼저 완료하세요. 작업 폴더는 **Dart 과정 루트**입니다.

```powershell
dart run "00. operator/main.dart"
```


## 코드 읽기

```dart
void main() {
  print(7 + 2);
  print(7 / 2);
  print(7 ~/ 2);
  print(7 % 2);
  print(80 >= 70 && 80 <= 100);
}
```

[실행 파일](main.dart)

## 예상 결과

```text
9
3.5
3
1
true
```

## 주의사항

문자열 결합과 숫자 덧셈을 혼동하지 마세요. 연산자 우선순위가 애매하면 괄호로 표현합니다.
