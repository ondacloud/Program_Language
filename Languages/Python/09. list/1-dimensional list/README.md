# 1차원 리스트

## 핵심 개념

다차원 리스트는 리스트 안에 리스트를 넣은 구조입니다. 각 행의 길이가 같아야 하는 제약은 없으므로 데이터 구조를 직접 관리합니다.

## 실행 예제

```python
values = [1, 2, 3]
for value in values:
    print(value)
```

## 실행 결과

```text
1
2
3
```

## 동작 원리와 주의사항

리스트는 `[[길이]]`로 선언하지 않습니다. 0이 3개인 리스트는 `[0] * 3`입니다.

## 직접 확인하기

한 원소를 수정한 뒤 다른 행이나 층이 함께 바뀌지 않는지 확인하세요.
