# 2차원 리스트

## 핵심 개념

다차원 리스트는 리스트 안에 리스트를 넣은 구조입니다. 각 행의 길이가 같아야 하는 제약은 없으므로 데이터 구조를 직접 관리합니다.

## 실행 예제

```python
matrix = [[0 for _ in range(3)] for _ in range(2)]
matrix[0][0] = 1
print(matrix)
```

## 실행 결과

```text
[[1, 0, 0], [0, 0, 0]]
```

## 동작 원리와 주의사항

`[[0] * 3] * 2`는 같은 행 객체를 두 번 참조합니다. 행마다 새 리스트를 만들려면 컴프리헨션을 사용합니다.

## 직접 확인하기
