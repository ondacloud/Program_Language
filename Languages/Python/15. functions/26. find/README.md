# str.find

## 핵심 개념

첫 부분 문자열 위치를 찾고 없으면 -1을 반환합니다.

## 실행 예제

```python
print("banana".find("na"))
print("banana".find("x"))
```

## 실행 결과

```text
2
-1
```

## 동작 원리와 주의사항

if text.find(...)는 잘못된 판단을 만들 수 있습니다. 위치 0은 거짓, -1은 참입니다. 포함 여부만 필요하면 in을 쓰세요.
