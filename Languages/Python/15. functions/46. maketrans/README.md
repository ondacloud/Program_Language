# str.maketrans

## 핵심 개념

문자별 변환·삭제 규칙을 담은 테이블을 만듭니다.

## 실행 예제

```python
table = str.maketrans("ab", "12", "!")
print("ab!ba".translate(table))
```

## 실행 결과

```text
1221
```

## 동작 원리와 주의사항

앞의 두 문자열 길이는 같아야 합니다. 세 번째 문자열은 삭제할 문자들입니다. 테이블만 만들며 실제 적용은 translate가 합니다.
