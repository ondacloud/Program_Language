# str.lower

## 핵심 개념

소문자로 변환한 새 문자열을 반환합니다.

## 실행 예제

```python
print("PYTHON".lower())
```

## 실행 결과

```text
python
```

## 동작 원리와 주의사항

Unicode의 대소문자 무시 비교에는 casefold도 고려하세요. lower 자체는 원본을 바꾸지 않습니다.

## 직접 확인하기

예제의 입력을 빈 값 또는 중복 값으로 바꾸어 반환값과 원본 변경 여부를 확인하세요.
