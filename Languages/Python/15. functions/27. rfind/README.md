# str.rfind

## 핵심 개념

가장 오른쪽 부분 문자열 위치를 찾고 없으면 -1을 반환합니다.

## 실행 예제

```python
print("banana".rfind("na"))
print("banana".rfind("x"))
```

## 실행 결과

```text
4
-1
```

## 동작 원리와 주의사항

시작·끝 범위를 지정할 수 있고 끝은 제외됩니다. str.rindex는 실패 시 예외를 발생시킨다는 차이가 있습니다.
