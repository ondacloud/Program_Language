# del

## 핵심 개념

이름 바인딩이나 컬렉션 항목을 제거하는 문입니다.

## 실행 예제

```python
values = [1, 2, 3]
del values[1]
print(values)
```

## 실행 결과

```text
[1, 3]
```

## 동작 원리와 주의사항

함수가 아니며 반환값이 없습니다. del name은 객체 자체의 즉시 파괴를 보장하지 않습니다. 다른 참조가 남을 수 있습니다.

## 직접 확인하기

예제의 입력을 빈 값 또는 중복 값으로 바꾸어 반환값과 원본 변경 여부를 확인하세요.
