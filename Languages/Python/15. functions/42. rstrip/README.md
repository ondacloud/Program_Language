# str.rstrip

## 핵심 개념

오른쪽 끝에서 공백 또는 지정한 문자 집합을 제거합니다.

## 실행 예제

```python
print("Helloabba".rstrip("ab"))
```

## 실행 결과

```text
Hello
```

## 동작 원리와 주의사항

chars는 접미사 자체가 아닙니다. 파일 확장자 제거에 rstrip(".txt")를 쓰면 예상보다 많이 지울 수 있습니다. 정확한 접미사는 removesuffix로 제거합니다.
