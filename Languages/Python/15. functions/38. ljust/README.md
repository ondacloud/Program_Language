# str.ljust

## 핵심 개념

왼쪽 정렬을 위해 오른쪽에 채움 문자를 붙입니다.

## 실행 예제

```python
print(repr("cat".ljust(5, "-")))
```

## 실행 결과

```text
'cat--'
```

## 동작 원리와 주의사항

width는 최소 너비이며 긴 문자열을 자르지 않습니다. fillchar는 길이 1인 문자열이어야 합니다.
