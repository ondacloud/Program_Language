# in — 포함 검사

## 핵심 개념

컬렉션에 값이 포함되는지 판단하는 연산자입니다.

## 실행 예제

```python
print("a" in {"a": 1})
print(1 in {"a": 1})
print("ana" in "banana")
```

## 실행 결과

```text
True
False
True
```

## 동작 원리와 주의사항

dict에서는 값이 아닌 키를 검사합니다. 값 검색은 d.values()에서 합니다. 문자열에서는 부분 문자열을 검사합니다. 함수가 아닙니다.

## 직접 확인하기

예제의 입력을 빈 값 또는 중복 값으로 바꾸어 반환값과 원본 변경 여부를 확인하세요.
