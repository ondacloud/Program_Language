# str.strip

## 핵심 개념

양쪽 끝의 공백 또는 지정한 문자 집합을 제거합니다.

## 실행 예제

```python
print("  a b  ".strip())
print("##hello##".strip("#"))
```

## 실행 결과

```text
a b
hello
```

## 동작 원리와 주의사항

문자열 중간 공백은 남깁니다. 새 문자열을 반환하며 원본을 수정하지 않습니다.
