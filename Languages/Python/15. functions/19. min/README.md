# min

## 핵심 개념

가장 작은 원소를 반환합니다.

## 실행 예제

```python
print(min([3, 1, 2]))
print(min([], default=0))
```

## 실행 결과

```text
1
0
```

## 동작 원리와 주의사항

빈 iterable에 기본값이 없으면 ValueError입니다. key로 비교 기준을 지정합니다. 여러 위치 인수 방식에는 default를 사용할 수 없습니다.

## 직접 확인하기

예제의 입력을 빈 값 또는 중복 값으로 바꾸어 반환값과 원본 변경 여부를 확인하세요.
