# max

## 핵심 개념

가장 큰 원소를 반환합니다.

## 실행 예제

```python
print(max([3, 1, 2]))
print(max(["a", "bbb"], key=len))
```

## 실행 결과

```text
3
bbb
```

## 동작 원리와 주의사항

동점이면 처음 만난 원소를 반환합니다. 빈 iterable의 기본값 처리는 min과 같습니다.

## 직접 확인하기

예제의 입력을 빈 값 또는 중복 값으로 바꾸어 반환값과 원본 변경 여부를 확인하세요.
