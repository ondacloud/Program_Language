# str.zfill

## 핵심 개념

최소 너비까지 왼쪽을 0으로 채웁니다.

## 실행 예제

```python
print("-42".zfill(5))
print("12345".zfill(3))
```

## 실행 결과

```text
-0042
12345
```

## 동작 원리와 주의사항

선행 부호 뒤에 0을 채웁니다. 너비보다 이미 길면 잘라내지 않습니다. 새 str을 반환합니다.
