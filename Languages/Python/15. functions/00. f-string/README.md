# f-string

## 핵심 개념

표현식을 문자열에 삽입합니다.

## 실행 예제

```python
name = "Alice"
score = 95.126
print(f"{name}: {score:.2f}")
```

## 실행 결과

```text
Alice: 95.13
```

## 동작 원리와 주의사항

새 str을 만듭니다. 중괄호 자체는 {{, }}로 표시합니다. 표시 정밀도는 원래 수를 바꾸지 않습니다.
