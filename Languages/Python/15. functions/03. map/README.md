# map

## 핵심 개념

함수를 각 원소에 지연 적용하는 iterator를 반환합니다.

## 실행 예제

```python
values = map(int, ["1", "2"])
print(list(values))
print(list(values))
```

## 실행 결과

```text
[1, 2]
[]
```

## 동작 원리와 주의사항

한 번 소비한 iterator는 다시 처음부터 반복하지 않습니다. 변환 오류는 실제로 원소를 꺼낼 때 발생할 수 있습니다.

## 직접 확인하기

예제의 입력을 빈 값 또는 중복 값으로 바꾸어 반환값과 원본 변경 여부를 확인하세요.
