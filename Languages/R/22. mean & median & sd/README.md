# 기초 요약 통계

## 핵심 개념

평균·중앙값·표준편차로 데이터를 요약합니다.

## 실행 방법

R 4.1 이상을 설치하고 이 폴더에서 `Rscript --vanilla main.R`로 실행합니다. R 콘솔에서는 작업 폴더를 이 폴더로 맞춘 뒤 `source("main.R")`로 실행할 수 있습니다. 외부 패키지는 필요하지 않습니다.

[실습 파일](main.R)

## 실행 예제

```r
x <- c(1, 2, 3, 4, 10)
cat(mean(x), median(x), min(x), max(x), "\n")
cat(round(sd(x), 3), "\n")
cat(quantile(x, probs = c(0.25, 0.75), names = FALSE), "\n")
```

## 예상 결과

```text
4 3 1 10 
3.536 
2 4 
```

## 동작 원리와 주의사항

sd는 표본 표준편차이며 분모에 n-1을 사용합니다. 결측값 정책과 분위수 계산 방식은 결과 해석에 영향을 줍니다. 요약값 하나만으로 분포를 판단하지 마세요.



## 직접 확인하기

극단값 10을 100으로 바꾸어 평균과 중앙값을 비교하세요.
