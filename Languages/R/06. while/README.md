# while

## 핵심 개념

조건을 먼저 검사하고 참인 동안 반복합니다.

## 실행 방법

R 4.1 이상을 설치하고 이 폴더에서 `Rscript --vanilla main.R`로 실행합니다. R 콘솔에서는 작업 폴더를 이 폴더로 맞춘 뒤 `source("main.R")`로 실행할 수 있습니다. 외부 패키지는 필요하지 않습니다.

[실습 파일](main.R)

## 실행 예제

```r
n <- 0
while (n < 3) {
  cat(n, "\n")
  n <- n + 1
}
```

## 예상 결과

```text
0 
1 
2 
```

## 동작 원리와 주의사항

조건은 길이 1의 NA가 아닌 논리값이어야 합니다. 갱신을 빼면 반복이 끝나지 않을 수 있습니다.



## 직접 확인하기

초기 n을 3으로 바꾸세요.
