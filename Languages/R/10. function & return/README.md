# function·return·기본 인수

## 핵심 개념

함수는 인수로 값을 받고 계산한 값을 반환합니다.

## 실행 방법

R 4.1 이상을 설치하고 이 폴더에서 `Rscript --vanilla main.R`로 실행합니다. R 콘솔에서는 작업 폴더를 이 폴더로 맞춘 뒤 `source("main.R")`로 실행할 수 있습니다. 외부 패키지는 필요하지 않습니다.

[실습 파일](main.R)

## 실행 예제

```r
add <- function(a, b = 1) {
  return(a + b)
}
cat(add(2), add(b = 3, a = 2), "\n")
```

## 예상 결과

```text
3 5 
```

## 동작 원리와 주의사항

마지막으로 평가한 표현식도 반환값이 됩니다. 이름으로 인수를 전달할 수 있고 기본 인수는 생략할 때 사용됩니다. 함수는 정의된 환경을 참조하므로 변수의 탐색 범위를 생각해야 합니다.
