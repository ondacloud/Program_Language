# 연산자·대입·자료형

## 핵심 개념

R의 기본 계산은 벡터 단위입니다. 대입·비교·논리 연산과 정수 나눗셈을 구분합니다.

## 실행 방법

R 4.1 이상을 설치하고 이 폴더에서 `Rscript --vanilla main.R`로 실행합니다. R 콘솔에서는 작업 폴더를 이 폴더로 맞춘 뒤 `source("main.R")`로 실행할 수 있습니다. 외부 패키지는 필요하지 않습니다.

[실습 파일](main.R)

## 실행 예제

```r
n <- 7
cat(n + 2, n / 2, n %/% 2, n %% 2, n ^ 2, "\n")
cat(n > 0 && n < 10, "\n")
cat(c(1, 2) + 10, "\n")
cat(typeof(1), typeof(1L), typeof(TRUE), "\n")
```

## 예상 결과

```text
9 3.5 3 1 49 
TRUE 
11 12 
double integer logical 
```

## 동작 원리와 주의사항

<-는 일반적인 대입 표기입니다. %%는 나머지, %/%는 정수 나눗셈, ^는 거듭제곱입니다. &·|는 요소별 논리 연산이고 &&·||는 길이 1 조건에 쓰는 단락 연산입니다. 길이가 다른 벡터는 재활용될 수 있어 의도치 않은 계산을 주의하세요. # 뒤는 주석입니다.
