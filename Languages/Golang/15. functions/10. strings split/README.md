# strings.Split

## 핵심 개념

구분자로 문자열을 나눠 []string을 반환합니다.

## 실행 예제

```go
package main

import (
    "fmt"
    "strings"
)

func main() {
    fmt.Printf("%q\n", strings.Split("a,,b", ","))
}
```

## 실행 결과

```text
["a" "" "b"]
```

## 동작 원리와 주의사항

연속 구분자는 빈 문자열을 남깁니다. 연속 공백을 묶어 나누려면 strings.Fields를 사용합니다. 원본 문자열은 바꾸지 않습니다.

## 직접 확인하기

입력을 빈 값·중복 값·경계값으로 바꾸어 결과와 원본 변경 여부를 확인하세요.
