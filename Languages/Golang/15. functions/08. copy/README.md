# copy

## 핵심 개념

slice 원소를 복사하고 복사한 개수를 반환합니다.

## 실행 예제

```go
package main

import (
    "fmt"
)

func main() {
    src := []int{1, 2, 3}
    dst := make([]int, 2)
    fmt.Println(copy(dst, src))
    fmt.Println(dst)
}
```

## 실행 결과

```text
2
[1 2]
```

## 동작 원리와 주의사항

복사 개수는 두 slice 길이 중 작은 값입니다. cap이 커도 len이 0인 목적지에는 복사하지 못합니다. 중첩 객체의 깊은 복사는 아닙니다.

## 직접 확인하기

입력을 빈 값·중복 값·경계값으로 바꾸어 결과와 원본 변경 여부를 확인하세요.
