# 산술·대입·증감 연산자

## 핵심 개념

PowerShell은 값의 타입에 따라 연산합니다. 숫자 계산과 문자열·배열의 +를 구별해야 합니다.

## 실행 방법

PowerShell 7에서 `pwsh -NoProfile -File ./example.ps1`로 실행합니다. 실행 정책이나 조직 정책이 막으면 오류 원인을 확인하고 관리 정책을 따르세요.

[실습 파일](example.ps1)

## 실행 예제

```powershell
$n = 7
"$($n + 2) $($n - 2) $($n * 2) $($n / 2) $($n % 2)"
$n += 3
$n++
$n
2 + 3 * 4
(2 + 3) * 4
'7' + 2
[int]'7' + 2
```

## 예상 결과

```text
9 5 14 3.5 1
11
14
20
72
9
```

## 동작 원리와 주의사항

왼쪽 피연산자 타입이 변환과 결과에 영향을 줄 수 있습니다. PowerShell에는 ** 거듭제곱 연산자가 없으므로 [Math]::Pow를 사용할 수 있습니다. 일반 증감 문장은 값을 출력하지 않지만 ($n++)처럼 괄호로 감싸면 결과가 출력될 수 있습니다.

## 문법 한눈에 보기

| 분류 | 문법 |
|---|---|
| 산술 | `+ - * / %` |
| 대입 | `= += -= *= /= %=` |
| 증감 | `++ --` |

## 직접 확인하기

문자열과 숫자의 피연산자 순서를 바꿔 비교하세요. [Math]::Pow(2,3)을 실행하세요.
