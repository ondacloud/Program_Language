# for

## 핵심 개념

초기값·조건·갱신식을 지정해 반복합니다.

## 실행 방법

PowerShell 7에서 `pwsh -NoProfile -File ./example.ps1`로 실행합니다. 실행 정책이나 조직 정책이 막으면 오류 원인을 확인하고 관리 정책을 따르세요.

[실습 파일](example.ps1)

## 실행 예제

```powershell
$sum = 0
for ($i = 1; $i -le 3; $i++) { $sum += $i }
$sum
```

## 예상 결과

```text
6
```

## 동작 원리와 주의사항

본문에서 출력한 객체는 성공 스트림으로 나갑니다. 합계만 필요하면 중간 디버깅 출력이 결과에 섞이지 않게 하세요.



## 직접 확인하기

조건을 -lt로 바꿔 결과를 확인하세요.
