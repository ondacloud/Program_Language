# 자료형과 연산자

## 핵심 개념

Python 변수는 객체에 붙이는 이름입니다. 대표 타입은 `int`, `float`, `bool`, `str`, `list`, `tuple`, `dict`, `set`입니다. `None`은 값이 없음을 나타냅니다.

## 실행 예제

```python
print(7 / 2, 7 // 2, -7 // 2, -7 % 2)
print(2 ** 3, 3 < 5, not [])
print("" or "guest")
print([1] and "ready")
print(~15)
```

## 실행 결과

```text
3.5 3 -4 1
8 True True
guest
ready
-16
```

## 동작 원리와 주의사항

- `/`는 나눗셈, `//`는 음의 무한대 방향으로 내림한 몫입니다. `int(-3.5)`의 0 방향 절삭과 다릅니다.
- 내장 숫자의 비교 결과는 `True` 또는 `False`입니다. `and`와 `or`는 항상 bool이 아니라 선택된 피연산자를 반환합니다.
- `==`는 값 비교, `is`는 같은 객체인지 검사합니다. `None` 확인은 `is None`을 씁니다.
- `in`은 포함 여부, `& | ^ ~ << >>`는 정수 비트 연산입니다. Python 정수는 고정된 8비트로 잘리지 않아 `~15 == -16`입니다.
- `=`는 대입입니다. 리스트의 `+=`는 객체를 직접 바꿀 수 있으므로 언제나 `a = a + b`와 완전히 같지는 않습니다.

## 타입 선택

| 타입 | 예 | 특징 |
|---|---|---|
| `int` | `42` | 메모리가 허용하는 범위에서 큰 정수 처리 |
| `float` | `3.14` | 이진 부동소수점, 반올림 오차 가능 |
| `str` | `"hello"` | 불변 Unicode 문자열 |
| `list` | `[1, 2]` | 순서 있음, 변경 가능 |
| `tuple` | `(1, 2)` | 원소 참조를 변경할 수 없음 |
| `dict` | `{"a": 1}` | 키·값 매핑, 삽입 순서 유지 |
| `set` | `{1, 2}` | 중복 제거, 순서 보장 없음 |

비어 있는 집합은 `set()`입니다. `{}`는 빈 딕셔너리입니다.
