# dict.update

## 핵심 개념

다른 매핑이나 키·값 쌍으로 원본을 갱신합니다.

## 실행 예제

```python
values = {"a": 1}
print(values.update({"a": 2, "b": 3}))
print(values)
```

## 실행 결과

```text
None
{'a': 2, 'b': 3}
```

## 동작 원리와 주의사항

같은 키는 새 값으로 덮어씁니다. 원본 변경, 반환값 None입니다. 중첩 dict를 자동 재귀 병합하지 않습니다.

## 직접 확인하기

예제의 입력을 빈 값 또는 중복 값으로 바꾸어 반환값과 원본 변경 여부를 확인하세요.
