# len

## 핵심 개념

길이를 지원하는 객체의 원소 수를 반환합니다.

## 실행 예제

```python
print(len("가나다"))
print(len({"a": 1, "b": 2}))
```

## 실행 결과

```text
3
2
```

## 동작 원리와 주의사항

모든 iterable이 len을 지원하는 것은 아닙니다. generator에는 일반적으로 길이가 없습니다. str 길이는 Unicode 코드 포인트 수이며 화면 글자 수와 다를 수 있습니다.

## 직접 확인하기

예제의 입력을 빈 값 또는 중복 값으로 바꾸어 반환값과 원본 변경 여부를 확인하세요.
