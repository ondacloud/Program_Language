# count

## 핵심 개념

일치하는 항목 또는 겹치지 않는 부분 문자열의 개수를 셉니다.

## 실행 예제

```python
print([1, 1, 2].count(1))
print("aaaa".count("aa"))
```

## 실행 결과

```text
2
2
```

## 동작 원리와 주의사항

str.count는 겹치는 일치를 세지 않습니다. 원본은 변경하지 않으며 없는 값은 0입니다.

## 직접 확인하기

예제의 입력을 빈 값 또는 중복 값으로 바꾸어 반환값과 원본 변경 여부를 확인하세요.
