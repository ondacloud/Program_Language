# str.format

## 핵심 개념

자리 표시자를 치환한 문자열을 만듭니다.

## 실행 예제

```python
print("{name}: {score:.1f}".format(name="Alice", score=9.25))
```

## 실행 결과

```text
Alice: 9.2
```

## 동작 원리와 주의사항

새 str을 반환합니다. 이름 또는 인덱스로 값을 지정합니다. 일반 출력 서식은 Python의 반올림 규칙과 부동소수점 표현의 영향을 받습니다.

## 직접 확인하기

예제의 입력을 빈 값 또는 중복 값으로 바꾸어 반환값과 원본 변경 여부를 확인하세요.
