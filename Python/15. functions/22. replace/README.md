# str.replace

## 핵심 개념

부분 문자열을 치환한 새 문자열을 반환합니다.

## 실행 예제

```python
text = "a-b-a"
print(text.replace("a", "x", 1))
print(text)
```

## 실행 결과

```text
x-b-a
a-b-a
```

## 동작 원리와 주의사항

원본 문자열은 불변입니다. count를 생략하면 모든 일치를 바꿉니다. 정규식이 아닌 문자 그대로의 부분 문자열을 찾습니다.

## 직접 확인하기

예제의 입력을 빈 값 또는 중복 값으로 바꾸어 반환값과 원본 변경 여부를 확인하세요.
