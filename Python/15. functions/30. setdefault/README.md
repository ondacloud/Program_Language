# dict.setdefault

## 핵심 개념

키가 없을 때만 기본값을 넣고 해당 키의 값을 반환합니다.

## 실행 예제

```python
groups = {}
groups.setdefault("a", []).append(1)
groups.setdefault("a", []).append(2)
print(groups)
```

## 실행 결과

```text
{'a': [1, 2]}
```

## 동작 원리와 주의사항

키가 이미 있으면 기존 값을 유지합니다. 기본값 표현식은 메서드 호출 전에 평가됩니다. 단순 조회이며 삽입이 필요 없다면 get을 사용하세요.

## 직접 확인하기

예제의 입력을 빈 값 또는 중복 값으로 바꾸어 반환값과 원본 변경 여부를 확인하세요.
