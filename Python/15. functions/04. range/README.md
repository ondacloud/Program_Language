# range

## 핵심 개념

정수 범위를 간결하게 표현하는 불변 시퀀스입니다.

## 실행 예제

```python
print(list(range(1, 6, 2)))
print(list(range(3, 0, -1)))
```

## 실행 결과

```text
[1, 3, 5]
[3, 2, 1]
```

## 동작 원리와 주의사항

stop은 제외됩니다. step은 0일 수 없습니다. range 자체는 모든 정수를 미리 리스트로 만들지 않습니다.
