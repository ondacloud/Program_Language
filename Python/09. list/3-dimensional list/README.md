# 3차원 리스트

## 핵심 개념

다차원 리스트는 리스트 안에 리스트를 넣은 구조입니다. 각 행의 길이가 같아야 하는 제약은 없으므로 데이터 구조를 직접 관리합니다.

## 실행 예제

```python
cube = [[[0 for _ in range(2)] for _ in range(2)] for _ in range(2)]
cube[0][1][1] = 7
print(cube[0])
print(cube[1])
```

## 실행 결과

```text
[[0, 0], [0, 7]]
[[0, 0], [0, 0]]
```

## 동작 원리와 주의사항

각 층과 각 행을 따로 생성해야 별칭으로 인한 연쇄 변경을 막을 수 있습니다.

## 직접 확인하기

한 원소를 수정한 뒤 다른 행이나 층이 함께 바뀌지 않는지 확인하세요.
