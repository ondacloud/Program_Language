# if — 조건 실행

## 핵심 개념

조건문은 참인 분기의 코드를 실행합니다. 콜론과 들여쓰기로 블록을 구분하며 같은 수준의 들여쓰기를 일관되게 맞춥니다.

## 실행 예제

```python
value = -1
if value < 0:
    print("negative")
```

## 실행 결과

```text
negative
```

## 동작 원리와 주의사항

`elif` 연결에서는 처음 참인 분기 하나만 실행합니다. 비교는 `==`이며 `elif value = 0:`은 문법 오류입니다. `None`, 0, 빈 문자열과 빈 컬렉션은 거짓으로 평가됩니다. 들여쓰기는 공백 4칸을 권장합니다.
