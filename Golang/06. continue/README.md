# continue — 다음 반복

## 핵심 개념

반복 제어는 함수 호출이 아닌 문장입니다. 종료와 건너뛰기의 범위를 구분하세요.

## 실행 예제

```go
package main

import (
    "fmt"
)

func main() {
    for i := 1; i <= 4; i++ {
        if i%2 == 0 {
            continue
        }
        fmt.Println(i)
    }
}
```

## 실행 결과

```text
1
3
```

## 동작 원리와 주의사항

현재 for 본문의 나머지를 건너뜁니다. 증감문이 있으면 실행하고 다음 조건을 검사합니다. 중첩 루프는 레이블로 대상 루프를 지정할 수 있지만 과도한 사용은 흐름을 복잡하게 합니다.

## 직접 확인하기

출력과 조건 검사 위치를 바꾸면 결과가 어떻게 달라지는지 확인하세요.
