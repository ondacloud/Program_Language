# break — 반복 종료

## 핵심 개념

반복 제어는 함수 호출이 아닌 문장입니다. 종료와 건너뛰기의 범위를 구분하세요.

## 실행 예제

```go
package main

import (
    "fmt"
)

func main() {
    for i := 1; i <= 5; i++ {
        if i == 3 {
            break
        }
        fmt.Println(i)
    }
}
```

## 실행 결과

```text
1
2
```

## 동작 원리와 주의사항

가장 가까운 for, switch, select를 종료합니다. switch 안의 break가 바깥 for까지 종료하는 것은 아닙니다. 중첩 루프는 레이블로 대상 루프를 지정할 수 있지만 과도한 사용은 흐름을 복잡하게 합니다.
