# Operator

## Data Type
|Data Type|Description|
|---|---|
|int|정수형 숫자|
|float32, float64|실수형 숫자|
|string|문자열|
|bool|참/거짓 값|
|array|고정된 크기의 연속 데이터 구조|
|slice|크기가 변경 가능한 연속 데이터 구조|
|map|Key-Value 쌍으로 구성된 데이터 구조|
|struct|여러 필드를 하나로 묶는 사용자 정의 자료형|

<br>

## Arithmetic Operator
|Operator|Description|
|---|---|
|+|두 값을 더합니다.|
|-|왼쪽 값에서 오른쪽 값을 뺍니다.|
|*|두 값을 곱합니다.|
|/|왼쪽 값을 오른쪽 값으로 나눕니다.|
|%|왼쪽 값을 오른쪽 값으로 나눈 나머지를 반환합니다.|

<br>

## Assignment Operator
|Operator|Description|Example|Same Operation Formula|
|---|---|---|---|
|=|오른쪽 값을 왼쪽 변수에 대입합니다.|a = b|-|
|+=|더한 결과를 다시 대입합니다.|a += b|a = a + b|
|-=|뺀 결과를 다시 대입합니다.|a -= b|a = a - b|
|*=|곱한 결과를 다시 대입합니다.|a *= b|a = a * b|
|/=|나눈 결과를 다시 대입합니다.|a /= b|a = a / b|
|%=|나머지를 다시 대입합니다.|a %= b|a = a % b|

<br>

## Relational Operator
|Operator|Description|
|---|---|
|<|왼쪽 값이 오른쪽 값보다 작은지 비교합니다.|
|>|왼쪽 값이 오른쪽 값보다 큰지 비교합니다.|
|==|두 값이 같은지 비교합니다.|
|!=|두 값이 다른지 비교합니다.|
|<=|왼쪽 값이 오른쪽 값보다 작거나 같은지 비교합니다.|
|>=|왼쪽 값이 오른쪽 값보다 크거나 같은지 비교합니다.|

<br>

## Logical Operator
|Operator|Description|
|---|---|
|&&|두 조건이 모두 참인지 확인합니다.|
|\|\||두 조건 중 하나 이상이 참인지 확인합니다.|
|!|논리값을 반전합니다.|

<br>

## Bit Operator

|\||Bit OR 연산|

|&^|Bit Clear 연산|
