# Go 자료형과 연산자

## 핵심 개념

Go는 정적 타입 언어입니다. `var`로 타입을 지정하거나 함수 안에서 `:=`로 타입을 추론하여 새 변수를 선언합니다.

## 실행 예제

```go
package main

import (
    "fmt"
)

func main() {
    a, b := 7, 2
    fmt.Println(a/b, float64(a)/float64(b), a%b)
    fmt.Println(a > b, a == b)
    var active bool
    var count int
    fmt.Println(active, count)
}
```

## 실행 결과

```text
3 3.5 1
true false
false 0
```

## 동작 원리와 주의사항

- 초기값을 생략하면 zero value를 가집니다. 숫자 0, bool false, string 빈 문자열, 포인터·slice·map·channel·함수·interface는 nil입니다.
- `int`는 구현에 따라 32비트 또는 64비트입니다. `int32`, `int64`처럼 고정 폭 타입도 있습니다.
- 숫자 타입 사이의 변환을 명시합니다. `float64(a/b)`는 정수 나눗셈 이후 변환하므로 3입니다.
- 비교 결과와 조건은 bool입니다. 정수 0을 조건에 직접 사용할 수 없습니다.
- `++`, `--`는 문장이므로 `x := i++`는 허용되지 않습니다. 전위 `++i`도 없습니다.

## 자주 쓰는 타입과 연산

| 분류 | 타입 / 연산 | 기억할 점 |
|---|---|---|
| 수치 | `int`, `uint`, `int64`, `float64`, `complex128` | 폭과 정밀도를 구분 |
| 문자 | `byte` = `uint8`, `rune` = `int32` | rune은 코드 포인트 표현에 사용 |
| 텍스트 | `string` | 불변 바이트열 |
| 자료구조 | array, slice, map, struct | 값 복사와 내부 데이터 공유를 구분 |
| 산술 | `+ - * / %` | `%`는 정수에 사용 |
| 비교 | `== != < <= > >=` | 타입별 허용 여부가 다름 |
| 논리 | `&&`, `\|\|`, `!` | 단락 평가 |
| 비트 | `&`, `\|`, `^`, `&^`, `<<`, `>>` | `&^`는 비트 제거 |

복합 대입은 `+=`, `-=`, `*=`, `/=`, `%=` 등을 씁니다. slice와 map은 서로 `==`로 비교할 수 없지만 nil과는 비교할 수 있습니다.
