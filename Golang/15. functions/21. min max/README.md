# min / max

## 핵심 개념

Go 1.21 이상에서 순서 비교 가능한 인수들의 최소·최대값을 구합니다.

## 실행 예제

```go
package main

import (
    "fmt"
)

func main() {
    fmt.Println(min(10, 20, 5))
    fmt.Println(max(10, 20, 5))
}
```

## 실행 결과

```text
5
20
```

## 동작 원리와 주의사항

적어도 한 인수가 필요합니다. min(values...)처럼 slice를 펼칠 수 없습니다. slice는 비어 있지 않은지 확인하고 slices.Min/Max를 사용하거나 반복합니다.

## 직접 확인하기

입력을 빈 값·중복 값·경계값으로 바꾸어 결과와 원본 변경 여부를 확인하세요.
