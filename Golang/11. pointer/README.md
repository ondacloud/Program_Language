# 포인터 — 주소와 값 변경

## 핵심 개념

&로 주소를 얻고 *로 역참조합니다. Go의 일반 포인터는 산술 연산을 지원하지 않습니다.

## 실행 예제

```go
package main

import (
    "fmt"
)

func double(value *int) {
    *value *= 2
}

func main() {
    value := 10
    double(&value)
    fmt.Println(value)
}
```

## 실행 결과

```text
20
```

## 동작 원리와 주의사항

nil 포인터를 역참조하면 panic입니다. 포인터를 전달해도 포인터 값 자체는 복사됩니다. 호출자의 포인터 재대입까지 바꾸려면 다른 설계가 필요합니다. Go는 필요할 경우 지역 값을 함수 이후에도 살려 두므로 C와 달리 지역 변수 주소 반환 자체가 잘못은 아닙니다.

## 직접 확인하기

포인터 대신 int를 받는 함수로 바꾸고 원본 값이 유지되는지 확인하세요.
