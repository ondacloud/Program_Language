# CSS 학습 가이드

분류용 상위 폴더 없이 실제 문법·함수 이름을 번호순으로 배치했습니다. 폴더에서 README와 실행 파일을 바로 확인하세요.

일반 프로그래밍 언어의 if·for 분류를 적용하지 않고 실제 태그·속성·선택자 이름으로 배치했습니다.

## 실행 환경

각 장의 example.html을 브라우저로 열고 style 블록을 수정해 확인합니다. 작은 화면과 키보드 초점을 함께 검사하세요.
