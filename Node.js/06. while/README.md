# while

## 핵심 개념

본문 실행 전에 조건을 검사하는 반복문입니다.

## 실행 방법

Node.js 24.x 환경에서 이 폴더의 `node example.mjs`를 실행합니다. 표준 모듈만 사용하는 예제는 npm install이 필요 없습니다.

[실습 파일](example.mjs)

## 실행 예제

```javascript
let n = 0;
while (n < 3) {
  console.log(n);
  n++;
}
```

## 예상 결과

```text
0
1
2
```

## 동작 원리와 주의사항

처음부터 조건이 거짓이면 본문은 한 번도 실행되지 않습니다. 조건을 바꾸는 갱신을 빠뜨리면 무한 반복이 생길 수 있습니다.



## 직접 확인하기

n의 초기값을 3으로 바꾸어 출력 여부를 확인하세요.
