# 자료형과 연산자

## 핵심 개념

C는 변수의 자료형을 선언합니다. 정수 나눗셈은 소수 부분을 버리고, 비교·논리 연산은 참이면 `1`, 거짓이면 `0`을 만듭니다. 조건에서는 0 이외의 값이 참입니다.

## 실행 예제

```c
#include <stdio.h>

int main(void) {
    int a = 7, b = 2;
    printf("%d %.1f %d\n", a / b, (double)a / b, a % b);
    printf("%d %d\n", a > b, a == b);
    unsigned int flags = 5u;
    printf("%u\n", flags & 1u);
    return 0;
}
```

## 실행 결과

```text
3 3.5 1
1 0
1
```

## 동작 원리와 주의사항

- `=`는 대입, `==`는 비교입니다. `(double)(a / b)`는 이미 잘린 결과를 변환합니다.
- `&&`, `||`는 단락 평가합니다. `&`, `|`, `^`, `~`는 비트 연산입니다.
- 후위 `i++`는 증가 전 값을, 전위 `++i`는 증가 후 값을 식의 값으로 사용합니다. `i++ + ++i`처럼 순서가 보장되지 않는 수정을 한 식에 섞지 않습니다.
- 부호 있는 정수 오버플로는 정의되지 않은 동작입니다. 부호 없는 정수는 타입 범위에 따라 순환합니다.
- C17에서 음수의 오른쪽 시프트는 구현 정의입니다. 비트 조작에는 부호 없는 타입을 우선 고려하고, 타입 비트 수 이상의 시프트는 피합니다.

## 자료형 크기와 범위

| 타입 | 표준에서 보장하는 기준 | 확인 방법 |
|---|---|---|
| `char` | `sizeof(char) == 1`; 1바이트의 비트 수는 최소 8 | `CHAR_BIT`, `CHAR_MIN`, `CHAR_MAX` |
| `short`, `int` | 최소 -32767 ~ 32767 표현 | `SHRT_MIN/MAX`, `INT_MIN/MAX` |
| `long` | 최소 -2147483647 ~ 2147483647 표현 | `LONG_MIN/MAX` |
| `long long` | 최소 -9223372036854775807 ~ 9223372036854775807 표현 | `LLONG_MIN/MAX` |
| `float`, `double`, `long double` | 정밀도와 범위가 구현에 따라 달라짐 | `<float.h>` |
| `_Bool` / `bool` | 0 또는 1; C17의 `bool`은 `<stdbool.h>` 필요 | `sizeof(bool)` |

`<limits.h>`와 `sizeof`로 실제 환경을 확인합니다. 흔한 32비트 `int`의 범위는 -2147483648 ~ 2147483647이지만 모든 C 구현에서 크기가 4바이트인 것은 아닙니다. `long`도 Windows와 다른 64비트 환경에서 크기가 다를 수 있습니다.

산술 `+ - * / %`, 복합 대입 `+= -= *= /= %=`, 비교 `< <= > >= == !=`, 조건 연산 `조건 ? 참값 : 거짓값`, 주소 `&`, 역참조 `*`, 크기 `sizeof`를 구분하세요.
