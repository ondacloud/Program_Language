# 인덱싱·논리 선택·which

## 핵심 개념

숫자·이름·논리값으로 원소를 선택합니다.

## 실행 방법

R 4.1 이상을 설치하고 이 폴더에서 `Rscript --vanilla main.R`로 실행합니다. R 콘솔에서는 작업 폴더를 이 폴더로 맞춘 뒤 `source("main.R")`로 실행할 수 있습니다. 외부 패키지는 필요하지 않습니다.

[실습 파일](main.R)

## 실행 예제

```r
values <- c(a = 10, b = 20, c = 30)
cat(values[c(1, 3)], "\n")
cat(values[values >= 20], "\n")
cat(which(values >= 20), "\n")
cat(values[-2], "\n")
```

## 예상 결과

```text
10 30 
20 30 
2 3 
10 30 
```

## 동작 원리와 주의사항

양수 인덱스는 선택, 음수는 제외입니다. 양수·음수 인덱스를 섞지 마세요. 논리 인덱스에 NA가 있으면 결과에도 NA가 들어갈 수 있습니다. which는 TRUE의 위치만 반환합니다.



## 직접 확인하기

없는 이름, 범위 밖 인덱스, NA를 포함한 조건을 비교하세요.
