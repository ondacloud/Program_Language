# JavaScript 학습 가이드

분류용 상위 폴더 없이 실제 문법·함수 이름을 번호순으로 배치했습니다. 폴더에서 README와 실행 파일을 바로 확인하세요.

## 실행 환경

터미널 예제는 Node.js에서 `node example.mjs`, 브라우저 예제는 `example.html`을 엽니다. Fetch·모듈·저장소 예제는 각 장의 HTTP 서버 안내를 따르세요.
